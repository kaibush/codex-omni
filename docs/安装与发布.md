# 安装与发布

本地开发继续用 `pnpm dev` / `pnpm dev:stable`。下面这条路径给**其他人安装并启动服务**用。

## 别人怎么用

机器需要 Node.js 20+，以及能跑 Codex 的环境（已登录 CLI，或稍后在网页里配置 Provider）。Linux 上 `node-pty` / `better-sqlite3` 如需编译，请准备 Python 3、`make` 和 C/C++ 编译器。

从 npm 安装最新版：

```bash
npm i -g @kaibush/codex-omni
codex-omni
```

或从 GitHub Release 安装：

```bash
npm i -g https://github.com/kaibush/codex-omni/releases/latest/download/codex-omni.tgz
codex-omni
```

如果手里已有本地包：

```bash
npm i -g ./codex-omni-0.1.0.tgz
codex-omni
```

或不用全局安装：

```bash
npx ./codex-omni-0.1.0.tgz
```

浏览器打开 `http://localhost:8790`。首次进入页面会引导创建管理员。也可以先建好账户：

```bash
codex-omni user create --username admin --password 'change-this-password'
```

常用参数：

```bash
codex-omni start --host 0.0.0.0 --port 8790 --data ./data/codex-omni.db
```

数据默认写在**当前工作目录**的 `data/codex-omni.db`。前端和 API 由同一个进程提供，不必再单独开 Vite。

## GitHub Release

打标签 `v0.1.0`（以及后续 `v*`）后，CI 会运行 typecheck / test / lint，创建 GitHub Release，并上传安装包。

用户始终可以从 npm 或 latest 下载地址安装：

```bash
npm i -g @kaibush/codex-omni
codex-omni
```

```bash
npm i -g https://github.com/kaibush/codex-omni/releases/latest/download/codex-omni.tgz
codex-omni
```

## 我们怎么打包

在仓库根目录：

```bash
pnpm pack:release
```

会构建协议包、Server、Web，然后生成：

- `release/codex-omni/` 可安装目录
- `release/codex-omni-0.1.0.tgz` npm 包（文件名保持 `codex-omni-*.tgz`，包内名称是 `@kaibush/codex-omni`）

把 tgz 发给别人，或发到 GitHub Release。

## 发布到 npm

确认包名、版本和仓库公开后。scoped 包已带 `publishConfig.access=public`：

```bash
pnpm pack:release
npm publish ./release/codex-omni-0.1.0.tgz --access public
```

发布成功后，别人可以：

```bash
npm i -g @kaibush/codex-omni
codex-omni
```

或：

```bash
npx @kaibush/codex-omni
```
